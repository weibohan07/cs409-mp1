02 / OPEN SOURCE

Selected projects.

A few open-source projects I have worked on, ranging from runtime infrastructure to HTTP systems and Markdown tooling.

PROJECT 001 / TYPESCRIPT

Syna.

A dependency and lifetime management system for stateful TypeScript services. It models how services are created, shared, reused, and disposed across different execution environments.

  • TypeScript
  • Runtime

PROJECT 002 / RUST

Oxidase.

A declarative HTTP service compiler and runtime written in Rust. Gateway configuration is compiled into an immutable runtime that can route, transform, proxy, and serve HTTP traffic.

  • Rust
  • HTTP

PROJECT 003 / MARKDOWN

remark-curly-directive.

A small syntax extension for the Unified and Remark ecosystem. It parses curly-brace directives such as {{...}} into typed MDAST nodes while keeping their meaning up to downstream plugins.

  • Remark
  • TypeScript
